# Dr. Pillareddy Vamsheedhar Reddy — Personal Website

A professional, minimal, and inspiring website for Dr. Vamsheedhar Reddy — Associate Professor, Researcher, and Mentor.

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- Mobile-first, accessible design

## Design

- Clean white background with navy and deep grey accents
- Minimal gold highlights
- Large hero typography with soft overlay on hero images
- Playfair Display (headings) + Source Sans 3 (body)

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Run development server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000).

3. **Build for production**
   ```bash
   npm run build
   npm start
   ```

## Assets

Hero slider images are in `public/images/` (hero1.png, hero2.png, hero3.png). To update them, replace the files in `public/images/` or copy from `assets/slides/`.
